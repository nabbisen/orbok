# RFC-052 Phase 1 — classified allowlist of data/technical string literals
# in designated UI/platform-integration files (HANDOFF-052 §2).
#
# Format (tab-separated): <file>\t<literal>\t<reason>
#
# Every entry here is a literal the checker's heuristic would otherwise flag
# as unrouted display copy, individually justified as data/technical rather
# than user-visible text (RFC-052 §6: "broad file or line-pattern exclusions
# are prohibited... every data/technical exception records its reason").
# A literal appearing in a designated file but NOT listed here is either (a)
# not matched by the heuristic at all (e.g. it flows through `tr()`), or (b)
# a real violation the gate is correctly failing on until Phase 2 fixes it —
# see docs referenced from review-request 132 for the list of those.
#
# Keyed on (file, literal) rather than line number, since line numbers shift
# on every unrelated edit; a literal recurring in one file needs one entry.

# ── Structural/decorative separators — BORDERLINE, see review-request 132 ──
# Recommend exempt: purely structural, byte-identical across locales
# per the established precedent of i18n.rs's own source_summary/
# fmt_storage_row formatters, which use identical " · " separators in both
# `en::message` and `ja::message`. Flagged for explicit reviewer
# confirmation rather than silently assumed, since RFC-052 §3 calls out
# "separator with semantic meaning" as requiring cataloguing.
crates/ui/src/views.rs	 · 	structural list separator between already-localized filter labels; byte-identical across locales elsewhere in i18n.rs (source_summary, fmt_storage_row) — recommend exempt, flagged for reviewer confirmation
crates/ui/src/views/wizard.rs	 · 	structural separator joining two data fields (model name, license); same precedent as above — recommend exempt, flagged for reviewer confirmation
crates/ui/src/views/wizard.rs	— {} —	decorative em-dash bracketing around an already-translated MessageKey ("or" separator); recommend exempt, flagged for reviewer confirmation since dash conventions can vary by locale/typography
